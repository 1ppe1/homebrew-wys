# Homebrew tap for wys

[wys](https://github.com/1ppe1/wys) is a statically typed, compiled language for programs that call LLMs and run tool-using agents, with capabilities, approvals, and budgets enforced by the runtime.

```sh
brew install 1ppe1/wys/wys
```

Supported: macOS arm64 and Linux x86_64. `wys` uses `clang` to link programs; on macOS, install the Xcode Command Line Tools (`xcode-select --install`).

The formula installs the release archives from [GitHub Releases](https://github.com/1ppe1/wys/releases) and checks their SHA-256. Issues about wys itself belong in [1ppe1/wys](https://github.com/1ppe1/wys/issues).
